## Project Overview

This project demonstrates the design, implementation, and troubleshooting of a multi-site enterprise network using Cisco Packet Tracer. The topology simulates connectivity between two geographically separated offices located in Panama and Kenya.

## Network Topology

* Cisco ISR4321 Routers
* Cisco Catalyst 2950 Switches
* Multiple Workstations
* IP Camera
* IoT Webcam
* WAN Serial Connection

## Key Features

* Multi-site WAN deployment
* Router-to-router serial connectivity
* LAN infrastructure configuration
* IP addressing and subnetting
* End-to-end communication testing
* IoT device integration
* Network troubleshooting and validation
